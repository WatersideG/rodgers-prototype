# Dealer brand logo collection log

Collected 2026-09-20. All files were downloaded as-is from the brand's own site (or its CDN), Wikimedia Commons, or extracted verbatim from the brand site's own inline header SVG. No logo was drawn or reconstructed. Where an inline SVG used a CSS variable / `currentColor` for its fill (no intrinsic color), the fill was set to `#000` and this is noted.

Every file was verified (PNG opened with PIL; SVG starts with `<svg`/`<?xml`). Files flagged **WHITE** are official files but are white-on-transparent and need a dark version or recoloring before use on a white wall.
